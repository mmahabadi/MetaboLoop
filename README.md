# MetaboLoop

MetaboLoop is a nutrition-tracking and adaptive diet-coaching app. It estimates
calorie/macro targets from user data and recalibrates them weekly by comparing
logged intake against actual weight-trend change — closing the loop between
what you eat and what your body does with it (hence the name).

This project is under active architectural planning. See [`DECISIONS.md`](./DECISIONS.md)
for the running log of confirmed technical decisions and their rationale.

## Status

🚧 Pre-implementation. Tech stack, architecture, and design system are being
decided via checkpoints before any application code is written.
